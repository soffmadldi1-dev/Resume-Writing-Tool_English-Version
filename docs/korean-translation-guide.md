# 영문 서류 → 한국어 번역 가이드 (강사용)

> 대상: 영문판 프롬프트 메이커(`index.html`)로 서류를 만든 외국인 유학생의 최종 영문 HTML을 한국어 제출본으로 바꿀 때
> 핵심: **직역하지 말고 '현지화'한다** — 문서별 문체 규칙 + 고유명사 확정 + 번역투 제거, 이 3가지를 순서대로.

---

## 1. 결론 한 줄

도구 안의 **프롬프트 ⑤(Korean Version)** 를 쓰세요. **새 채팅**에 최종 영문 HTML을 첨부하고 ⑤를 붙여넣으면, 레이아웃·사진·차트는 그대로 두고 글자만 한국어 제출 문체로 바뀝니다. 강사는 마지막에 **10분 검수(아래 5번)** 만 하면 됩니다.

## 2. 왜 그냥 번역하면 어색해지나 — 원인 3가지

| 원인 | 증상 | ⑤ 프롬프트의 대응 |
|---|---|---|
| ① 문체 체계가 다름 | 영어 이력서의 "Handled 80 check-ins a day"를 "하루 80건의 체크인을 처리했습니다"처럼 문장형으로 옮김 → 한국 이력서답지 않음 | 문서별 문체 고정: 이력서 = 개조식 명사형(~응대/~수행), 자소서 = 합니다체, 포트폴리오 = 명사형 + 카드 문장만 합니다체 |
| ② 고유명사 표기 | 학교·학과·회사·자격증을 임의로 번역 ("Hotel Management Dept." → '호텔경영학과'? '호텔관광경영학과'?) → 사실 오류 | 번역 **전에** 표기표를 먼저 만들고, 확신 없는 항목은 '확인 필요'로 표시 → 학생에게 영어로 질문 |
| ③ 번역투 | '저는' 반복, '~을 가지고 있습니다', '~에 대한', '~들', 피동문 | 14개 번역투 패턴 점검 후 수정 결과만 반영 |

> 영문판 프롬프트 ①~④ 도 처음부터 **번역하기 쉬운 영어**(관용구 금지, 짧은 문장, 숫자는 아라비아 숫자, 날짜 YYYY.MM, 고유명사 고정)로 쓰도록 설계해 두었습니다. 그래서 ⑤의 한국어 품질이 올라갑니다.

## 3. 작업 흐름 (권장)

| 단계 | 하는 일 | 목적 / 리스크 |
|---|---|---|
| 1 | 학생이 ①~④ 를 한 채팅에서 완료 → 최종 영문 HTML 저장 | 영문 내용 확정. 영문 단계에서 사실·숫자를 끝까지 확정해야 번역 후 수정이 줄어듦 |
| 2 | **새 채팅**을 열고 영문 HTML 첨부 + 프롬프트 ⑤ 붙여넣기 | 긴 대화 맥락이 섞이지 않아 결과가 안정적. ⑤에는 학생 입력값(이름·한글 이름·학교 등)이 이미 들어 있음 |
| 3 | AI가 낸 '확인 필요' 질문(영어)에 학생이 답 → 같은 파일명으로 재생성 | 이름·학교·회사명 오류는 치명적이므로 반드시 확인 |
| 4 | 강사 10분 검수 (5번 체크리스트) | 마지막 어색함·사실 오류 차단 |
| 5 | 크롬 Ctrl+P → PDF로 저장(여백 없음, 배경 그래픽 체크) | 제출본 완성 |

**사진 팁:** 사진이 base64로 들어간 HTML은 파일이 매우 커서 번역 결과가 깨지거나 느려질 수 있습니다. **사진 넣기 전 영문 HTML을 번역**하고, 한국어 채팅에서 사진을 다시 올리는 순서가 가장 안전합니다. (코드 실행 도구가 있는 클로드는 텍스트만 치환하도록 프롬프트에 지시해 두었습니다.)

**학생이 도구 없이 HTML만 가져온 경우:** 맨 아래 7번의 '단독 프롬프트'를 쓰세요. [참고 정보] 칸만 채우면 됩니다.

## 4. 학생에게 미리 받아 둘 정보 (번역 정확도를 가장 많이 올리는 3가지)

1. **한글 이름 표기** — 외국인등록증·통장·학생증·아르바이트 계약서에 쓰는 한글 표기. 중국어권 학생은 한자음(왕위)과 원어 발음(왕웨이) 중 무엇을 쓰는지 꼭 확인.
2. **학교·학과 공식 한글명** — 학생증이나 학교 홈페이지 그대로. (학과명은 학교마다 달라 AI가 추측하면 틀리기 쉬움)
3. **근무처 공식 상호** — 아르바이트·인턴 회사의 한국어 상호 (예: "XX Hotel" → 실제 상호)

→ 도구 STEP 1에 '한글 이름', STEP 2 학력 칸에 '공식 한글명을 괄호로 적기' 안내를 넣어 두었습니다.

## 5. 강사 10분 검수 체크리스트

- [ ] 성명이 '한글 이름 (영문 여권명)' 형식인가? 학생이 확인한 표기인가?
- [ ] 학교·학과·회사·자격증 이름에 '확인 필요' 항목이 남아 있지 않은가?
- [ ] 이력서(P1)가 끝까지 개조식 명사형인가? '~했습니다'가 섞이지 않았는가? 마침표가 없는가?
- [ ] 자소서(P2)가 합니다체로 통일됐는가? '저는'이 문단마다 반복되지 않는가?
- [ ] 자소서 글자 수(공백 포함)가 Q1 400~500 / Q2 500~600 / Q3 400~500 / Q4 300~400자 범위인가? 지원 기업 제한이 있으면 그 기준인가?
- [ ] 영문판의 숫자가 한국어판에 모두 같은 값으로 있는가? (⑤가 숫자 대조 결과를 한 줄로 보고함)
- [ ] '외국인이라 부족하지만' 같은 자기 비하·양해 표현이 없는가? 모국어·다문화 경험이 강점으로 쓰였는가?
- [ ] TOPIK·체류자격 표기가 'TOPIK 4급', 'D-2(유학)' 형식이고, 학생 입력값과 같은가?
- [ ] '귀사' 대신 기업명을 썼는가?
- [ ] 휴대폰 폭에서 가로 스크롤이 없고, 한글 단어가 중간에 끊기지 않는가?

## 8. 단독 프롬프트 (도구 없이 영문 HTML만 있을 때 — 새 채팅에 HTML 첨부 후 붙여넣기)

도구의 ⑤ 프롬프트와 같은 내용입니다. [참고 정보] 칸만 채워서 쓰세요.

```text
# 역할
당신은 한국 관광산업 채용 서류를 14년간 첨삭해 온 한국어 취업문서 편집자이자, 영한 전문 번역가입니다. 당신의 일은 '직역'이 아니라 '현지화'입니다 — 한국 채용담당자가 읽었을 때 처음부터 한국어로 쓴 서류처럼 읽히게 만드는 것.

# 목표
이 채팅에 첨부된(또는 위 대화에서 만든) 최종 영문 HTML 서류 — P1 이력서 / P2 자기소개서 / P3 취업 포트폴리오 — 를 자연스러운 한국어 제출본으로 바꾸세요. 레이아웃·디자인·사진·차트 좌표는 그대로 두고 '글자만' 한국어로 교체합니다.
※ 지원자는 한국어가 서툰 외국인 유학생입니다. 서류는 한국어로 쓰되, 지원자에게 하는 질문·안내·설명은 모두 영어로 하세요.

[참고 정보 — 아래 칸을 채워 주세요. 모르면 비워 두세요]
- 영문 이름(여권): 
- 한글 이름: (없으면 비워 두기 — 외래어 표기법으로 음역하고 확인 필요로 표시)
- 국적: 
- 체류자격(비자): 
- 지원 직무: 
- 지원 기업: 
- 한국어 능력: 
- 학력(학교·학과 공식 한글명을 알면 함께): 

# 진행 순서 (이 순서 고정)
STEP 1. 고유명사·용어 표기표 — 번역 전에 먼저 표로 확정
  | 영문 원문 | 한국어 표기 | 근거(지원자 입력 / 공식 명칭 / 외래어 표기법 / 업계 통용) | 확신도(확실 / 확인 필요) |
  · 대상 : 지원자 이름, 국적, 학교·학과, 회사·기관명, 자격증·시험명, 직함, 프로그램·행사명.
  · 지원자 이름 : 위 [참고 정보]의 한글 이름이 있으면 그대로 사용. 없으면 국립국어원 외래어 표기법 기준으로 음역하고 '확인 필요'. 문서의 성명 칸은 '한글 이름 (영문 여권명)' 형식으로 병기 (예: 응우옌 반 안 (NGUYEN VAN AN)). 중국어권 이름은 한자음 표기와 원어 발음 표기가 갈리므로 반드시 '확인 필요'.
  · 한국 학교·기업·기관 : 공식 한글 명칭을 쓴다. 공식 명칭이 확실하지 않으면 지어내지 말고 '확인 필요'. 학과명은 학교마다 다르므로 지원자가 적지 않았다면 '확인 필요'.
  · 해외 학교·기관 : '한글 음역(영문 공식명)' 형식으로 첫 등장 시 병기 (예: 하노이대학교(Hanoi University)).
  · 한국 국가자격은 공식 한국어 명칭으로 되돌린다 (예: Tourist Interpretation Guide → 관광통역안내사). 외국 시험·자격은 영문 그대로 (TOEIC, MOS, HSK).

STEP 2. 문서별 문체 규칙에 맞춰 번역 — 문체를 섞지 말 것
  [P1 이력서]
  · 헤드라인 : 명사로 끝나는 한 문장 (예: 하루 80팀 체크인을 3개 국어로 응대한 호텔 인턴 출신 프론트 지원자).
  · 핵심 역량 3줄·경력 성과·기타 활동 : 개조식 명사형 종결 (~응대 / ~수행 / ~달성 / ~작성 / ~운영). '~했습니다'·'~함' 금지, 문장 끝 마침표 없음.
    예) Handled about 80 check-ins a day for guests from 20+ countries → 20개국 이상 투숙객 대상 일 평균 약 80팀 체크인 응대
  · '→ 직무 연결' 줄 : '→ '로 시작하는 명사형 한 줄 (예: → 다국어 응대 경험으로 프론트 업무 즉시 투입 가능).
  · 자기소개(이력서 3번 칸) : 합니다체, 공백 포함 300자 내외.
  [P2 자기소개서]
  · 합니다체(~습니다/~했습니다)로 통일. 해요체·반말·'~하였사옵니다' 같은 과잉 존대 금지.
  · 분량(공백 포함 한글 글자 수) : Q1 400~500자 / Q2 500~600자 / Q3 400~500자 / Q4 300~400자. 기업이 정한 글자 수가 있으면 그 기준을 따른다.
    모자라면 영문 원문에 있는 사실을 풀어 쓰는 범위에서만 보강하고, 넘치면 수식어부터 줄인다. 새 사실·숫자 추가 금지.
  · 각 문항 끝의 '(XX words)'는 공백 포함 한글 글자 수로 다시 세서 '(○○자)'로 바꾼다.
  · 소제목은 영어 문장을 옮기지 말고, 같은 의미의 한국어다운 짧은 명사구·문장으로 새로 쓴다 (15자 내외).
  [P3 포트폴리오]
  · 칩·표·라벨 : 명사형. 05 카드의 '할 일'은 '~합니다'로 끝나는 한 문장(40자 내외), 카드 아래 요약도 '~재현합니다'.
  · 레이더 차트 축 이름은 한국어 6자 이내 + 점수 (예: Guest Care 5 → 고객응대 5). 표의 강점명과 똑같이 맞출 것.
```

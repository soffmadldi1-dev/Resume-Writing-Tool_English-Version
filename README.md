# Resume · Self-Intro · Portfolio Prompt Maker — English Edition

한국에 유학 중인 외국인 대학생(한국어가 서툰 학생)을 위한 **영문판** 이력서·자기소개서·포트폴리오 프롬프트 메이커입니다.
학생이 영어로 질문에 답하면 → 영문 서류(①~④)가 만들어지고 → 프롬프트 ⑤로 같은 디자인의 **자연스러운 한국어 제출본**까지 만들 수 있습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 영문판 도구 (브라우저로 열면 바로 실행, 설치 불필요) |
| `docs/korean-translation-guide.md` | 강사용 한국어 번역 가이드 — 작업 흐름, 검수 체크리스트, 번역투 Before/After, 용어 대조표, 단독 번역 프롬프트 |

## 한국어 원본 대비 바뀐 점

- 화면·예시·프롬프트 ①~④ 전부 영어로 (예시는 외국인 유학생 상황에 맞게 다시 작성)
- 입력 항목 추가: 한글 이름, 국적, 체류자격(비자), 한국어 능력(TOPIK·KIIP), 모국어 포함 기타 언어
- 영문 프롬프트에 '번역하기 쉬운 영어' 규칙 추가 (관용구 금지, 짧은 문장, 숫자·날짜 표기 고정, 고유명사 고정)
- 자소서는 서양식 커버레터가 아닌 **한국식 4문항 자기소개서** 구조 유지 (분량은 단어 수 기준)
- 레이더 차트 캔버스 좌우 여백 확대 (영문 라벨 잘림 방지 — 좌표값은 원본과 동일)
- 최종 문서(④)를 '번역 준비형'으로 생성 (모든 글자를 HTML 텍스트로, 고정 높이 지양)
- **프롬프트 ⑤ Korean Version 신설** — 최종 영문 HTML을 레이아웃 그대로 한국어 제출본으로 현지화 (질문·안내는 학생에게 영어로, 핵심 문장 영어 역번역 제공)
- 복사 버튼 예외 처리 (파일로 열었을 때 클립보드 실패 시 대체 복사 + 안내)

## 사용 순서 (학생)

1. `index.html`을 크롬으로 열고 STEP 1~4 입력
2. STEP 5에서 ①→②→③→④ 프롬프트를 **같은 Claude 채팅**에 차례로 붙여넣기 → 영문 A4 서류 HTML
3. **새 채팅**에 영문 HTML 첨부 + ⑤ 붙여넣기 → 한국어 제출본 HTML
4. 크롬 Ctrl+P → PDF로 저장 (여백 없음 · 배경 그래픽 체크)
